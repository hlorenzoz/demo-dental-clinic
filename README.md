# Aura Dental Collective - Minimalist Teal
A luxury clinical experience where restorative art meets advanced dental precision.

## 🎨 Aesthetic
- **Theme**: Restorative Sanctuary (Minimalist Teal)
- **Primary Color**: `#006565`
- **Typography**: Noto Serif / Manrope

## 🚀 Deployment (Vercel)

This project is optimized for deployment on Vercel:

1. Connect your GitHub account to [Vercel](https://vercel.com).
2. Click **Add New** > **Project**.
3. Import the repository: `dental-clinic-1-minimalist`.
4. Framework Preset: **Next.js**.
5. Click **Deploy**.

## 🛠️ Local Development

```bash
bun install
bun dev
```
