# Aura Dental Collective - Minimalist Teal
A luxury clinical experience where restorative art meets advanced dental precision.

## 🎨 Aesthetic
- **Theme**: Restorative Sanctuary (Minimalist Teal)
- **Primary Color**: `#006565`
- **Typography**: Noto Serif / Manrope

## 🚀 Deployment (Cloudflare Pages)

This project is optimized for Cloudflare Pages. Since it's already on GitHub:

1. Go to [Cloudflare Pages](https://dash.cloudflare.com/?to=/:account/pages).
2. Click **Create Application** > **Connect to Git**.
3. Select this repository: `template-website-dental-minimalist-teal`.
4. Framework Preset: **Next.js**.
5. Click **Save and Deploy**.

## 🛠️ Local Development

```bash
bun install
bun dev
```
